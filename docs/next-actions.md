## 점검 근거
- 같은 IKEA 냄비 URL 60484245: 홈 facts는 인덕션/가스 미확인, 비교 attributes는 가능. 상세 후보 1개와 비교 6개 모델도 분리돼 있다.
- 냉동밥·운동복 세제·냄비 검색 결과 있음. 1인용 밥솥은 0개이며 해당 제품 확보 여부를 별도 검수해야 한다. 규격을 추정해 결과를 만들지 않는다.
- 302개 용도 중 53개가 6모델 미달, 20개는 2개 미만, 부족 176연결. 정수 포트·드럼 세탁기·헹구는 트리트먼트·거치형 변기세정제 등 0개, 커튼·행거·선반 등 1개 용도가 있다.
- 대표 카드 1,908건 중 비마케팅 확인 속성 3개 미만 619건, 우선 두 값 모두 미확인 1,036건. 쿠팡 정확 상품 1건/제품명 검색 1,907건. 같은 모델의 여러 용도를 포함한 연결 수이며 고유 상품 수가 아니다.
- 입력: product-catalog.js, assets/comparison/*.json, comparison-display.js, 로컬 DOM. UI 검사가 데이터 정합성 해결을 뜻하지 않는다. 이미지 권한·가격 갱신·실사용 전환은 별도 미확인이다.
