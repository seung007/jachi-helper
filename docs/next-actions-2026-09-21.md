## 1순위 검증 기록 (2026-09-22)

- 홈·상세·결과가 품목별 안내를 공통 사용한다. 베개에 창문 규격, 종량제 봉투에 조리기구 조건이 나오는 공통 문구를 제거했다.
- 기본 분류와 사용자가 직접 선택한 상태를 구분하고, 필요함·나중에 선택 이유를 결과에 표시한다. 기본 분류는 편집 기준이며 개인에게 검증된 구매 필요성이나 인기도가 아니다.
- 종량제 봉투·분리배출은 관련 정보 검색, 상비약은 약국 검색으로 연결한다. 판매처 홈과 네이버 통합검색은 목적지에 맞는 이름을 표시한다. 외부 사이트의 검색 성공이나 보안 확인 해소를 보장하지 않는다.
- `scripts/verify-item-guidance.mjs`: 39개 전체 안내 누락, 분류, 조건 반영, 사용자 선택, 홈 예시, 링크 구성 검사. `npm run check`에 포함했다.
- 로컬 브라우저: 베개 홈 검색→상세 설명 일치, 조건 입력→결과, 멀티탭 필요함→새로고침 유지→나중에 이동, 베개 이미 있음→제외 확인. 필요함 선택 후 열린 조건 확인 목록 유지. 콘솔 오류 없음.

## 홈 필터 개선 확인 (2026-09-22)

- 채찍단(https://www.cowlr.kr/)의 검색·카테고리·보조 필터 구분을 참고했다. 가격 순위 기능을 그대로 복제한 것은 아니다.
- 생활 방식 영역을 기존 여러 버전의 공통 스타일에서 분리하고, 검은 배경과 중첩 스크롤을 없앴다. PC 4열, 모바일 2열로 네 선택지를 모두 표시한다.
- 모바일 카테고리는 4열 두 줄로 표시한다. 라디오와 키보드 초점으로 선택 상태를 구분한다.
- 브라우저 너비 320·390·768·1280px에서 페이지 및 필터 내부 넘침 없음. 클릭과 방향키 선택 시 관련 여섯 품목 갱신 확인. 320px에서는 긴 선택지 문구가 줄바꿈된다.
- `전체`은 모든 카테고리를 뜻하고 초기에는 대표 6개를 보여 준다. `39개 전체 보기`로 같은 화면에서 전부 펼치고 `대표 6개만 보기`로 접을 수 있다. 검색·개별 카테고리에서는 일치 항목을 모두 표시한다.
- CSS·JS 주소에 버전을 붙이고 로컬 서버에 `Cache-Control: no-store`를 추가해 이전 검은 필터 화면이 캐시에 남는 문제를 줄였다.
- 로컬 브라우저에서 6→39→6개 전환, 욕실 6개 전체 표시, 모바일 390px에서 39개 확장 후 가로 넘침 없음과 콘솔 오류 없음을 확인했다.
- 이번 범위는 홈 필터다. 첫 화면 전체 높이와 다른 페이지의 모바일 레이아웃 점검은 남아 있다. 커밋·푸시·배포하지 않았다.

## 커밋 승인 원칙

사용자가 상시 커밋 승인을 철회했다. 로컬 수정 및 검증은 진행하되, 변경 결과를 보고하고 명시적 허락을 받은 뒤에만 커밋한다. 푸시·배포도 승인 범위를 확인한다.

`docs/jachi-git.rules`는 이 컴퓨터의 자취도우미 경로와 원격 저장소를 지정한다. 커밋·푸시는 `prompt`로 변경했다. 사용자 설정의 `~/.codex/rules/jachi-helper.rules`에 설치하고 Codex를 재시작한다. 도구의 승인 처리와 별개로 에이전트는 AGENTS.md에 따라 사용자에게 명시적 허락을 받아야 한다.

대안은 기능 브랜치에 자동 커밋/푸시하고 미리보기 검증 후 main으로 병합하는 방식이다. 협업자가 늘거나 운영 영향이 커질 때 적용한다.
