## 가격·계산 규칙

- `shopping-offers.js`에 판매 옵션과 확인 시각을 기록한다. 일반가만 사용하고 회원가, 쿠폰, 배송비는 제외한다.
- 100ml당 가격 = 확인 금액 / (개당 ml * 수량) * 100. 화면 반올림 전 값으로 정렬한다.
- 1회당 세제비 = 사용자가 확인한 구매 금액 / 총 ml * 사용량 ml. 임의의 공통 권장 사용량은 넣지 않는다. 용기 표기 사용량은 세탁량·오염도별로 다를 수 있다.
- 확인 후 24시간은 보수적으로 정한 내부 노출 한도이지 가격 유효 보장이 아니다. 한도가 지나면 카드의 금액과 단위 가격을 숨긴다. 열린 탭에서도 1분 간격으로 확인한다. 방문·정렬이 확인 시각을 갱신하지 않는다.
- 만료 뒤에도 정확한 옵션 링크와 사용자가 입력하는 계산은 유지한다. 자동 수집/자동 갱신은 구현하지 않았다.
- 기본 순서는 데이터 등록 순서다. 시장 최저가·인기순·효능순이라고 주장하지 않는다.

## 성능 근거

2025년 한국소비자원 자료의 8종은 별도 성능 비교로 유지한다. 이전 문서의 홈 2025년 사용비 노출 방침은 이번 변경으로 대체한다. 구매 카드에 해당 자료 가격을 판매가처럼 표시하지 않는다. 과거 가격은 비교 상세의 접힌 자료 기준에만 남긴다.

액츠 판매 페이지에 리뉴얼 전후 혼합 배송 안내가 있어 과거 시험 제품과 동일한 배합이라고 단정하지 않았다. 테크는 제목과 일부 상품 정보의 세탁기 종류가 달라 이번 판매 카드에서 제외했다. 스너글의 20ml 표기는 적용 세탁량을 확인하지 못해 권장량으로 선입력하지 않았다.

## 남은 작업

1. 상품 이미지 재사용 권한과 공식 가격 공급 경로 확보 후 배포 승인.
2. 다른 품목은 동일한 구조로 옵션·단위·공식 성능 근거를 확보한 뒤 추가. 57개 품목 분류가 57개 검증 상품이라는 뜻은 아니다.
3. 가격 자동 갱신이 없으면 24시간 뒤 가격 비교가 비활성화되는 운영 한계가 있다. 최신성 없이 숫자를 유지하는 방식으로 해결하지 않는다.
