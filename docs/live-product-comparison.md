# 실제 상품 비교의 미래 기준

> 현재 단계에서는 활성화하지 않는다. 지금 서비스의 목적은 사용자가 준비물을 클릭으로 정리하고 구매 순서를 결정하는지 검증하는 것이다. 제휴 가입, API 키, 수수료 고지는 실제 사용자 행동이 확인된 뒤에 검토한다.

## 사용자에게 보이는 기준

- 실제 판매처 응답에서 받은 상품명, 이미지, 가격, 원본 링크만 보여 준다.
- 예산을 항목 수로 나눈 값, AI가 추정한 값, 과거에 수집한 값을 현재 가격처럼 표시하지 않는다.
- 가격 데이터가 없거나 API가 실패하면 가격 카드를 비우고 이유를 표시한다.
- 상품을 다시 불러온 시각과 데이터 출처를 함께 표시한다.

## 나중에 연결할 경로

쿠팡 파트너스 상품 API를 후보로 검토한다. 연결한다면 사용자가 요청한 순간에만 최대 3개 상품을 조회하고, 서버와 브라우저 모두 가격을 현재 가격처럼 장기 캐시하지 않는다.

쿠팡 파트너스 API는 상품 정보와 파트너스 링크를 웹/앱에 적용하기 위한 API라고 명시한다. 상품 데이터가 표시될 때는 수수료 가능성을 화면에 함께 고지한다.

- 쿠팡 파트너스 가이드: https://partners.coupangcdn.com/partners-guide/partners-guide-20241202161107.pdf
- 쿠팡 Open API가 셀러 운영용이라는 범위 확인: https://developers.coupang.com/ko

네이버 개발자센터의 쇼핑 검색 API는 2026년 7월 31일 종료되었으므로 범용 상품 비교 원천으로 사용하지 않는다.

- 네이버 종료 공지: https://developers.naver.com/notice/article/32973

## 활성화 조건

아래 조건이 모두 충족될 때만 구현한다.

1. 실제 사용자에게서 “목록 정리 후 제품을 비교하고 싶다”는 반복 행동 또는 인터뷰 근거가 나온다.
2. 쿠팡 파트너스에서 웹 또는 앱용 API 키를 발급받는다.
3. Vercel 프로젝트 `Settings > Environment Variables`에 아래 두 값을 등록한다.
   - `COUPANG_PARTNERS_ACCESS_KEY`
   - `COUPANG_PARTNERS_SECRET_KEY`
4. 새 배포 후 상품명, 가격, 이미지, 링크가 함께 오는지 수동 확인한다.

키는 `.env`, GitHub, 브라우저 코드에 넣지 않는다.

## 다음 확장 조건

다른 판매처를 더할 때도 같은 응답 형태로 어댑터를 추가한다. 판매처 간 가격을 한 카드에서 비교하려면 모든 판매처가 허용한 공식 제휴 또는 상품 데이터 API가 있어야 한다. 웹 페이지 크롤링으로 가격을 채우지 않는다.
