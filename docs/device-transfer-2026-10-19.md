# 노트북 이전 안내

2026-10-19 사용자 승인: 최신 프로젝트 코드·문서를 커밋/푸시하고, 비공개 자료는 별도 ZIP으로 이전한다. 이 승인은 새로운 UI 구현이나 Vercel CLI 운영 배포 승인이 아니다. GitHub 연동 배포가 설정되어 있다면 푸시로 자동 실행될 수 있다.

## 백업 구성

백업은 저장소 밖의 형제 폴더 `jachi-helper-transfer-2026-10-19/`에 둔다. ZIP은 GitHub나 공개 사이트에 올리지 않는다.

| 폴더 | 파일 | 내용 |
|---|---|---|
| 01-project | jachi-helper-project.zip | 현재 소스·문서·상품 자료·수집/분석 전체·서울 DB·검사 결과. 환경변수, .git, node_modules, Python 캐시는 제외 |
| 02-sources-and-workspace | jachi-helper-sources-workspace.zip | 바탕화면 대화 원문·첨부·시안·해당 프로젝트 화면 이미지·개인 스킬·작업 지침·관련 자동화 참고 파일 |
| 03-environment-private | jachi-helper-environment-PRIVATE.zip | 프로젝트 .env/.env.local 및 개인 Codex config.toml. 민감 정보 포함 가능. 다른 ZIP과 분리 보관 |

각 ZIP 안에 파일 크기·SHA-256 원장을 넣고 모든 항목을 다시 읽어 검증한다. 생성 후 validation-report.json에 실제 개수와 검증 결과를 남긴다. 파일이 만들어졌다는 것과 다른 기기로 복사가 끝났다는 것은 다르다.

커밋 전 검사: SEO/66개 안내/전체 171개, 생활 서비스 16개, 생활 화면 20개, 상품 홈·상세 6폭, 비교 화면·실제 데이터 통합 4폭, 제품 규격 9분류×4폭이 통과했다. 첫 전체 검사는 샌드박스의 localhost EACCES로 실패했으며 로컬 연결을 허용한 동일 검사 재실행에서 통과했다. 검사 시 서버 주소는 http://127.0.0.1:4173 이었다. 알려진 비밀 값과 개인 키 헤더 검사에서 커밋 대상 누출은 발견되지 않았다. 이 검사는 모든 비밀 형식의 부재를 보증하지 않는다.

## 새 노트북에서 복원

1. 본인 저장장치나 비공개 클라우드로 ZIP 세 개를 옮긴다. 빌린 노트북에만 있는 ZIP은 외부 백업이 아니다.
2. Node.js 24.15.0은 현재 검증에 사용한 버전이다. Git을 준비하고 `git clone https://github.com/seung007/jachi-helper.git`을 실행한다.
3. 코드는 GitHub 최신 버전을 사용한다. 01 ZIP은 8ca4240 시점 백업이므로 최신 코드 위에 통째로 덮어쓰지 않는다. ZIP에서 `jachi-helper/data/exports/`, 필요한 `output/`·`artifacts/` 등 Git 제외 자료를 같은 프로젝트 경로에 복원한다. `data/exports/`를 빼면 서울 장소 검색과 분석 재현이 불가능하다.
4. 03 ZIP의 `project/.env`와 `project/.env.local`을 프로젝트 루트에 놓는다. 키를 채팅에 붙이거나 Git에 추가하지 않는다. 개인 config.toml은 경로·도구·현재 설정과 대조하는 참고용이며 무조건 덮어쓰지 않는다.
5. 프로젝트에서 `npm ci`, `npm run check`, `npm run check:life`, `npm run serve`를 실행한다. 기본 미리보기는 http://localhost:4173 이다. 브라우저 검사는 로컬 Edge 설치 경로를 확인하고 BASE_URL을 실제 서버 주소에 맞춘다.
6. 02 ZIP은 원문/참고/개인 환경을 구분해 복원한다. 스킬은 새 Codex 설치의 사용자 스킬 경로를 확인한 뒤 필요한 것만 옮기고, 자동화는 참고 사본만 보존한다. 오래된 경로·일정·권한을 검토하기 전 자동 활성화하지 않는다.
7. GitHub·Vercel·Codex·연결 플러그인은 새 기기에서 본인 계정으로 다시 로그인/연결한다. auth.json, 브라우저 프로필·쿠키·OS 자격증명·전체 앱 세션 DB는 이 백업에 포함하지 않는다. 브라우저의 저장 상품·비교·지역 선택도 별도 localStorage여서 프로젝트 ZIP으로 이전되지 않는다.
8. 새 기기에서 소스/문서·서울 검색·환경변수·원문 존재를 확인한 뒤 빌린 노트북의 로그아웃/자료 정리를 한다. 이번 작업은 원본 삭제나 계정 로그아웃을 수행하지 않는다.

## 확인 한계

- 예전에 언급한 `Desktop/자취 관련 대화내역.txt`는 원래 경로에서 발견되지 않았다. 존재하는 `자취.txt`와 `ㄴ/생활 대화내역.txt`, 프로젝트 내부의 분석 원장은 보존한다. 찾지 못한 원본을 확보했다고 표시하지 않는다.
- 모든 과거 첨부나 전체 Codex 대화 이력의 백업은 아니다. 이 대화에서 경로가 확인된 첨부와 현재 작업을 이어 갈 프로젝트 문서를 보존한다.
- 개인 Codex 설정은 [공식 설정 문서](https://learn.chatgpt.com/docs/config-file/config-basic)를 참고해 새 환경과 대조한다. 설정 파일이 있다고 로그인·플러그인 연결·실행 바이너리까지 이전되는 것은 아니다.
- 환경변수 ZIP은 암호화되지 않은 민감 파일이다. 공개 업로드·공유 링크를 금지하고 본인만 접근하는 저장소에 보관한다.
