# 벤치마킹 맥락 기록

이 문서는 대화가 길어져도 사용자 지정 레퍼런스와 다른 목적의 사례를 혼동하지 않기 위한 인계 기록이다. 사용자가 새 대상을 제시하면 기존 목록의 빈칸과 관계없이 추가하고, 제안인지 확정인지 함께 기록한다.

2026-09-28 사용자 명시: 현재 메인은 생활용품 추천·구매다. 대화 분석은 제품 구매에 우선 적용하고, 이사 등 추가 사이드 흐름은 나중에 진행한다. 서비스는 기존 연결 4개를 남기되 전체 시장이나 유일한 추천처로 간주하지 않는다. 앞선 에이전트의 서비스 문의 확장을 현재 우선순위로 재사용하지 않는다.

| 대상 | 확인된 역할 | 근거와 상태 |
| --- | --- | --- |
| 채찍단 (`cowlr.kr`) | 첫 화면의 탐색 구조와 상품 비교 벤치마크 | 사용자 지정. `docs/promotion-playbook-2026-09-06.md`, `docs/product-data-direction-report-source-2026-09-09.md`에도 기록됨 |
| 오늘의집 (`ohou.se`) | 사용자 지정 벤치마크 | 사용자가 이번 대화에서 다시 명시함. 구체적으로 어느 화면과 패턴을 채택할지는 미확정 |
| 쿠팡 (`coupang.com`) | 판매 옵션·가격·단위 가격·구매 연결 벤치마크 | 2026-09-29 사용자 추가 지시. 과거 미확인 세 번째 사이트를 소급 확정한 것이 아님. 2026-10-06 상품 페이지 재확인 |
| 미소·짐싸·빼기 | 생활 서비스의 역할·책임 구조 조사 사례 | `docs/product-data-direction-report-source-2026-09-09.md`의 출처 표. 사용자 지정 UI 벤치마크로 확인되지 않음 |

과거에 언급된 "참고 사이트 3개"의 정확한 세 번째 이름은 현재 확인한 대화와 문서에서 특정되지 않았다. 이 과거 기록의 빈칸을 추측해 채우지 않되, 사용자의 새 지시로 참고 사이트를 추가하는 데 제한을 두지 않는다. 사이트를 확인하더라도 공개 화면에서 관찰한 기능과 성장·전환 효과의 인과 주장은 분리한다.

## 구매 카드 적용 (2026-10-06)

- 채찍단에서 관찰: 총가격과 기준 단위당 가격을 함께 표시. 채택: 구매 금액과 100ml당 금액을 구분한다.
- 쿠팡에서 관찰: 정확한 용량·수량, 일반가/회원가, 옵션별 상품 이미지와 링크. 채택: 확인한 일반 판매가와 정확한 옵션 링크, 묶음 수량을 표시한다. 조건부 할인·배송 혜택을 일반가에 섞지 않는다.
- 오늘의집 쇼핑에서 관찰: 상품 사진과 브랜드·상품명·가격이 중심. 채택: 실제 판매 옵션 사진과 상품명이 구매 카드의 첫 정보가 된다. 후기·인기도는 우리 데이터처럼 복제하지 않는다.
- 성능 근거는 별도 비교자료로 보존한다. 새 판매 옵션에 과거 배합의 시험 성능을 자동으로 붙이지 않는다.
- 이 화면 관찰은 유입·전환 증가가 입증됐다는 뜻이 아니다.

## 상품 탐색 적용 (2026-10-10)

- 사용자 지정 채찍단·오늘의집·쿠팡의 공개 화면을 상품 탐색·사진·저장·판매처 연결에 적용했다.
- 새 참고 제안: IKEA(제품 중심 이미지와 분류), 다나와(정확한 모델·규격), 노써치(구매 기준과 상품 자료 구분). 과거 사용자 합의로 소급하지 않는다.
- 실제 적용 범위와 성공 근거의 한계는 [이미지·UI 개선 기록](ui-benchmark-2026-10-10.md)에 남겼다. 특정 UI가 유입·매출을 증가시켰다는 인과 효과는 미확인이다.
