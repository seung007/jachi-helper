# 자취 단톡방 대화: 초기 문제 사례 메모

> 필요시 읽는 당시 근거/검토 기록이다. 최신 상태는 [현재 작업](current-work.md), 방향·실행 규칙은 [제품 방향](product-vision.md)과 [AGENTS](../AGENTS.md)를 따른다. 아래 제안·실험 문턱·당시 승인·집계는 현재 명령이나 새 작업의 승인으로 재사용하지 않는다.

> 이 문서는 처음 제공된 5일 표본에 대한 초기 메모다. 이후 91일 전체 내역을 분석한 [전체 분석](field-chat-analysis-2026-09-23.md)을 우선 참고한다.

## 자료와 해석 범위

- 자료: 사용자가 제공한 `자취 관련 대화내역.txt`의 2026-09-03~09-07 대화. 약 4,800줄이며 생활 잡담과 자동 메시지도 포함한다.
- 수집 경위와 원본의 완전성은 사용자 설명에 따른다. 참여자 수, 질문자별 중복, 실제 행동 결과는 확인하지 않았다.
- 아래는 **전수 코딩이나 빈도 순위가 아닌 초기 사례 추출**이다. 한 사람이 이어서 묻는 질문을 독립 수요 여러 건으로 세지 않는다.
- 원본의 닉네임, 장소, 금액, 원문, 채팅 링크는 이 문서에 복사하지 않는다. 원본 파일을 저장소에 추가하거나 외부 서비스로 전송하지 않는다.
- 이후 같은 방의 2026-06-25~09-23 전체 내역을 다시 받아 구조화했다. 현재 판단에는 이 초기 메모보다 [전체 분석](field-chat-analysis-2026-09-23.md)과 비공개 데이터셋을 사용한다.

## 확인한 질문 사례

줄 번호는 사용자가 제공한 로컬 원본 기준이다. 아래 내용은 직접 인용이 아닌 요약이다.

| 원본 줄 | 상황과 사용자가 묻는 결정 | 제품 관점 |
| --- | --- | --- |
| 97~170 | 세탁기에서 물이 새는 상황에서 사용 중단 여부와 연락할 곳을 묻는다. | 문제 발생 직후의 다음 행동과 연락 주체를 빠르게 찾고 싶다. |
| 3368~3377 | 세탁조 청소 후에도 잔여물이 남아 세탁을 계속해도 되는지 묻는다. | 일반 청소 팁보다 증상별 점검 순서가 필요하다. |
| 580~628 | 보증금 지급 문제에서 누구에게 어떻게 문의할지 묻는다. | 위험도가 높은 계약 문제는 공식 정보·전문가 연결이 우선이다. |
| 3774 이후 | 신탁회사 소유 주택 계약에서 확인할 서류의 충분성을 묻는다. 뒤의 대화 일부는 삭제되어 결론을 확인할 수 없다. | 개인별 법률 판단을 자동으로 단정하면 안 된다. |
| 3827~3831 | 입주 후 해충이 나타났을 때 임대인에게 방역을 요청할 수 있는지 묻는다. | 상태 기록, 문의 대상, 후속 조치가 궁금한 문제다. |
| 3880~3886 | 원룸에서 종량제 봉투 용량을 어떻게 선택할지 묻는다. | 공간, 배출 주기, 냄새 같은 조건을 반영한 소액 구매 결정이다. |
| 4356~4359 | 월세지원 대상에서 벗어난 뒤 보증금을 높이고 월세를 낮추는 방안을 묻는다. | 비용 계산뿐 아니라 제도 확인과 협상 가능성 검토가 필요하다. |
| 4541 | 청소기 구매에서 이사할 때 가져갈 수 있는지 등을 고려해야 한다는 의견이 나온다. | 최저가만이 아닌 이동성·생활 조건을 비교 기준으로 삼을 수 있다. |
| 4599~4605 | 좁은 집에서 분리수거 용기를 어디에 둘지 묻는다. | 제품 추천 이전에 공간 배치와 보유품을 확인해야 한다. |

## 제품 판단

**확인:** 이 표본에는 상품명·최저가 요청만이 아니라, 사고 대응, 계약 확인, 주거비, 작은 생활 선택처럼 "내 상황에서 다음에 무엇을 할지" 묻는 사례가 있다. 단톡방 답변은 서로 다른 의견이 섞일 수 있으므로, 채팅 답변 자체를 검증된 지침으로 재사용하지 않는다.

**가설:** 현재 첫 자취 준비 흐름에서는 품목별 판매처 링크보다 선택 기준과 다음 행동을 명확히 하는 편이 일부 질문에 더 직접적으로 답할 수 있다. 종량제 봉투·청소기·세탁 관리처럼 조건을 물은 뒤 선택지를 좁히는 작은 실험이 적합하다. 이 파일만으로 기능의 전체 수요 순위나 구매 전환 효과를 단정할 수는 없다.

**경계:** 세탁기 누수 같은 긴급 문제는 안전·제조사·임대인 연락 순서를 별도 검증한 뒤 안내한다. 보증금, 신탁, 월세지원, 임대인의 방역 책임은 개인별 법률·제도 판단을 제공하지 않고 공식 기관 또는 자격 있는 전문가로 연결한다. 이는 `docs/product-vision.md`의 현재 `안내` 단계와 일치한다.

## 다음 검증

1. 전체 대화를 `질문 상황 / 결정해야 할 일 / 받은 답 / 실제 해결 확인 여부`로 익명 코딩한다. 잡담과 중복 질문을 제외한 **문제 사례 수**를 따로 센다.
2. 반복 사례가 확인되면 현재 준비물 화면의 한 품목에서 조건 질문과 다음 행동을 시험한다. 결과는 클릭보다 사용자가 결정을 끝냈는지로 본다.
3. 이 단톡방 외의 자료나 실제 사용자 인터뷰로 같은 문제가 재현되는지 확인한 뒤 범위를 넓힌다.
