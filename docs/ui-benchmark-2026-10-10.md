# 상품 이미지와 탐색 UI 개선

> 필요시 읽는 당시 근거/검토 기록이다. 최신 상태는 [현재 작업](current-work.md), 방향·실행 규칙은 [제품 방향](product-vision.md)과 [AGENTS](../AGENTS.md)를 따른다. 아래 제안·실험 문턱·당시 승인·집계는 현재 명령이나 새 작업의 승인으로 재사용하지 않는다.

## 범위

현재 메인은 먹거리·생활용품 추천, 비교 기준, 구매 연결이다. 이사·서비스 신청 화면을 홈의 중심으로 확장하지 않는다. 사용자 지정 레퍼런스는 채찍단·오늘의집·쿠팡이며, IKEA·다나와·노써치는 이번 작업에서 추가한 참고 제안이다.

## 성공 근거의 경계

- 쿠팡은 2025년 4분기 Product Commerce 활성 고객 2,460만 명을 공시했다. 상업적 규모의 근거이지 특정 카드 UI의 전환 효과를 입증한 수치가 아니다. [공식 실적 발표](https://ir.aboutcoupang.com/news-events/news/news-details/2026/Coupang-Announces-Results-for-Fourth-Quarter-2025/default.aspx)
- IKEA는 FY25 총 소매 매출 446억 유로, 온라인 판매 비중 28%를 공개했다. 이 역시 온라인 사업의 규모를 보여 주며 특정 UI의 인과 효과는 확인하지 못했다. [공식 FY25 보고](https://www.ikea.com/global/en/our-business/how-we-work/year-in-review-fy25/)
- 오늘의집·채찍단·다나와·노써치의 현재 성과 수치와 위 패턴별 전환 효과는 이번 작업에서 검증하지 않았다. 구조 참고와 성공 수치를 구분한다.

## 이미지·링크 처리

- 기존 213개 품목 / 215개 상품 후보 / 공식 안내 3개 범위는 유지했다.
- 실제 상품 이미지 URL은 132개에서 215개로 채웠다. 누락 83개뿐 아니라 원래 있었지만 브라우저에서 실패한 사진도 대체 출처를 확인했다.
- 상품명·모델·용량·묶음 수량을 확인했다. 여러 옵션을 함께 보여 주는 사진은 `옵션 대표 이미지`라고 표시한다.
- 제조사·판매처의 공개 상품 자료를 사용하며, 차단·보안 확인을 우회하지 않았다. 공개 이미지의 표시 확인이 장기 사용권·제휴 계약 확보를 뜻하지는 않는다.
- 홈페이지로 이동하던 오래된 링크, 다른 모델 사진, 판매 옵션과 맞지 않던 규격을 정정했다. 최신 가격·재고·배송은 판매처에서 확인한다.
- 대화 원문과 내부 출처 검토 기록은 비공개 `data/exports/`에 유지한다.

## UX 변경

- 모바일 첫 상품이 더 빨리 보이도록 상단 설명과 필터 높이를 줄였다.
- 모바일 2열 / 중간 화면 3열 / 넓은 화면 4열 상품 탐색을 사용한다.
- 사진 비율 고정, 상품명·본문·버튼 글자 크기 정리, 버튼 최소 높이 44px.
- 저장 시 카드 전체를 다시 그리지 않아 사진 재로딩과 포커스 이동을 줄인다.
- 선택한 필터를 개별 해제할 수 있고, 정렬·필터는 URL로 복원한다.
- 상세 창에서 사진·제품 규격·판매처를 앞세운다. 닫으면 원래 카드와 스크롤 위치로 돌아간다.
- 저장 완료·실패 알림, 링크 복사, 맨 위로 이동, 초기 이미지 우선 로딩을 제공한다.
