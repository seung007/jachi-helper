# 초기 서비스 결정 기록

작성일: 2026-08-25
근거: `docs/market-research-2026-08-25.md`, `docs/product-vision.md`

## 결정

초기 서비스는 **첫 자취 구매 계획**으로 한정한다.

사용자가 몇 번의 선택만으로 `지금 필요`, `조건 확인`, `나중에 결정`, `이미 있음`을 나누고, 각 항목의 이유·구매 기준·판매처 검색어를 받는 도구다.

이것은 쇼핑몰, 상품 가격 비교 서비스, 이사·청소 중개 플랫폼, 종합 자취 포털이 아니다.

## 왜 이 선택인가

### 확인된 사실

- 1인 가구와 임차 생활은 큰 생활 맥락이지만, 이것만으로 특정 기능의 구매 의향이 증명되지는 않는다.
- 이사·청소·정리수납은 이미 실행 플랫폼이 제공하고, 상품 가격·재고·배송 정보는 판매처가 더 신뢰할 근거를 가진다.

### 추론

- 사용자에게 남는 공백은 "어디서 살까" 이전의 "내 상황에서 무엇을 사야 하나, 무엇을 미뤄도 되나"라는 결정일 가능성이 있다.
- 이 공백은 실제 상품 데이터나 제휴 없이도 작게 검증할 수 있고, 결정 결과와 제외 사유가 다음 카탈로그 개선 데이터가 된다.

## 첫 화면부터 결과까지의 한 흐름

1. **입구**: "입주 전에 꼭 살 것만 골라보기"
2. **선택**: 보유 여부와 생활 조건을 클릭한다.
   - 상태: 필요함 / 이미 있음 / 나중에 볼게요
   - 조건: 요리 빈도, 실내 건조, 운동복 세탁, 향 민감도, 수납 여유 등
   - 예산: 선택 입력이며, 필수 입력폼이 아니다.
3. **결과**: 세 목록으로 나눈다.
   - 지금 필요: 입주 직후 생활·안전에 직접 필요한 항목
   - 조건 확인: 집 옵션이나 보유품을 확인한 뒤 정할 항목
   - 나중에 결정: 사용 패턴이 생긴 뒤 사도 되는 항목
4. **다음 행동**: 각 항목에 결정 이유, 구매 기준, 검색어를 제공하고 사용자가 판매처에서 최종 확인한다.

`14일 전`은 입주 전 준비라는 맥락 설명으로만 유지한다. 모든 계약·행정·구매에 적용되는 보편적 기한이나 서비스의 핵심 약속으로 쓰지 않는다.

## 지금 하지 않을 것

- 실시간 가격, 재고, 배송, 판매 순위, 최저가 주장
- 상품 자체 순위와 AI가 만든 성능·효능 설명
- 제휴 수익을 전제로 한 링크 우선 노출
- 이사·청소·부동산·법률을 한 제품에서 직접 중개
- 상세 주소, 계약서, 개인식별정보 수집
- RAG, LangChain, LangGraph를 클릭형 규칙 흐름에 먼저 도입

## AI 도입 판단

초기 우선순위는 사용자가 고른 상태와 조건을 해석하는 결정론적 규칙으로 만든다.

- **RAG**: 근거 문서가 충분히 쌓여, "왜 이 기준인가"를 출처와 함께 설명해야 할 때 검토한다.
- **LangChain**: 공식 상품·파트너 데이터 조회, 리트리버, 추가 질문을 연결할 복수 도구 흐름이 생길 때 검토한다.
- **LangGraph**: 사람의 검토·수정·재개가 필요한 장기 추천 흐름이 생길 때 검토한다.

AI를 붙이는 조건은 기존 제품 비전의 `실제 사용자 5명 이상이 구매 결정을 완료하고 누락·불필요·불만족 사유를 기록`한 뒤다. 상품 가격·재고·배송은 공식 또는 제휴 데이터가 있어야 한다.

## 반증 조건과 다음 결정

아래가 나오면 이 결정을 유지하지 않는다.

| 관찰 | 해석 | 다음 행동 |
| --- | --- | --- |
| 사용자가 결과를 보고도 무엇을 사거나 미룰지 결정하지 못함 | 계획이 추상적이거나 입력 조건이 부족함 | 항목을 늘리지 말고 이유·조건·검색어를 수정 |
| 대부분이 단순 체크만 하고 결과를 보지 않음 | 구매 계획 자체의 효용이 약하거나 입구 약속이 틀림 | 특정 카테고리 문제로 좁혀 재검증 |
| 특정 카테고리에서만 반복적으로 도움을 받음 | 종합 자취보다 세분화된 문제에 공백이 있음 | 그 카테고리의 깊은 도구를 우선 검증 |
| 누락·불필요 피드백이 반복됨 | 카탈로그와 규칙의 근거가 약함 | 사용자 언어와 실제 보유품 기준으로 수정 |

## 검증 순서

1. 최근 독립했거나 곧 입주할 사용자 10명의 실제 준비 행동을 인터뷰한다.
2. 익명 이벤트로 시작, 조건 선택, 결과 도달, 필요/보유/보류 결정, 판매처 검색 진입, 누락·불필요 피드백을 기록한다.
3. 최소 5명의 사용자가 끝까지 구매 결정을 남긴 뒤, 그 결정을 바꾼 이유와 실제 결과를 확인한다.
4. 그 후에만 카탈로그 확장, 제휴, 공식 상품 데이터 연동, AI 도입을 재심의한다.

## 심의의 한계

이 기록은 하나의 모델이 관점을 나눠 검토한 결과이며, 독립적인 사용자 조사나 실험 결과가 아니다. 따라서 위 반증 조건을 충족하는 데이터가 나오면 이 결정을 바꾼다.
