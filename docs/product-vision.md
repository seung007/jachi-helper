# 자취도우미 제품 비전과 확장 원칙

## 1. 최종 목표

자취도우미는 물건이나 업체를 나열하는 사이트가 아니라, 사용자가 주거 생활에서 해야 할 다음 행동을 정리하고 신뢰할 수 있는 선택지로 연결하는 중간 관리자다.

장기적으로는 아래 순환을 지원한다.

`계약 -> 이사 준비 -> 입주 -> 생활 관리 -> 퇴실 -> 청소·처분 -> 다음 집`

사용자는 검색, 비교, 예약, 준비물 누락에 쓰는 시간과 심리적 부담을 줄이고, 서비스는 사용자의 상황에 맞는 정보와 파트너를 투명하게 연결한다.

## 2. 현재 집중 범위

현재의 한 가지 문제는 **첫 자취 입주 전 14일 준비**다.

- 초기 비용과 월 예산을 분리해 본다.
- 준비물을 체크하고 실제 구매 결정을 남긴다.
- 입주 전, 입주 첫 주, 입주 후로 행동을 나눈다.
- 판매처 검색으로 다음 행동을 시작한다.

`14일 전`은 현재 제품의 집중 범위이며 모든 사용자에게 적용되는 법적·보편적 기한이라는 뜻이 아니다. 계약·신고·점검의 기한은 지역, 계약 조건, 개인 상황에 따라 달라질 수 있다.

## 3. 제품의 두 역할

### 입구가 되는 문제: Painkiller

계약, 이사, 입주, 청소, 폐기물, 주소 변경, 필수 구매처럼 놓치면 시간·비용·스트레스가 커지는 일을 돕는다. 처음 방문하고 제휴 전환이 발생할 가능성이 높은 영역이다.

### 재방문을 만드는 문제: Vitamin

세제, 침구, 수납, 청소, 식재료, 주변 생활 시설처럼 생활에 맞는 선택을 돕는다. 예를 들어 운동 빈도, 세탁기 종류, 향 민감도, 의류 소재, 실내 건조 여부에 따라 세제 조건을 좁힌다.

AI는 조건을 설명하고 다음 질문을 고르는 역할을 한다. 상품의 효능, 가격, 재고, 배송 가능 여부를 추측해서는 안 된다.

## 4. 차별화 원칙

서비스를 많이 모으는 것만으로는 차별점이 되지 않는다. 차별점은 사용자의 주거 상태와 선택 이력을 바탕으로 지금 필요한 다음 행동을 줄이는 데 있다.

- 사용자의 입주일, 방 조건, 보유품, 예산, 취향을 필요한 범위에서만 받는다.
- 추천마다 왜 지금 필요한지, 어떤 입력값을 반영했는지 보여준다.
- 판매처·업체로 이동하기 전 가격, 재고, 배송, 서비스 범위, 제휴 여부를 명확히 알린다.
- 체크리스트에서 이미 준비한 물품과 나중에 결정할 물품을 구분해 반복 추천하지 않는다.

## 5. AI 맞춤 추천의 도입 조건과 구조

현재는 규칙 기반 추천을 유지한다. 다음 조건을 모두 충족하기 전에는 AI API와 실시간 상품 추천을 도입하지 않는다.

1. 제휴 또는 공식 데이터로 상품명, 가격, 재고, 배송, 카테고리, 수수료, 갱신 시각을 받을 수 있다.
2. 초기 사용자 5명 이상이 현재 추천 흐름에서 실제로 구매 결정을 완료했고, 누락·불필요·불만족 사유를 기록했다.
3. 제휴 링크, 광고·수수료 표시, 오류·품절 대응 책임 범위를 정했다.
4. API 비용과 악용 방지를 위한 사용량 제한을 준비했다.

도입 후 LangGraph 흐름은 다음처럼 제한한다.

`입력 검증 -> 필요한 추가 질문 -> 공식·제휴 후보 조회 -> 예산·조건 필터링 -> 추천 이유 생성 -> 판매처 확인 안내`

- LLM은 공식·제휴 데이터 밖의 가격, 재고, 배송, 성능을 만들어 내지 않는다.
- 계산 중에는 실제 진행 상태를 보여 주는 로딩 화면을 제공한다.
- 결과에는 조건 일치 이유, 데이터 갱신 시각, 판매처 링크, 제휴·광고 표시를 함께 제공한다.
- 개인식별정보와 상세 주소는 추천에 필요하지 않은 한 받지 않는다.

## 6. 수익화 원칙

1. 준비물: 투명하게 표시한 제휴 링크 또는 판매 수수료
2. 생활 서비스: 검증된 파트너에게 연결한 유효 상담·예약 리드 수수료
3. 나중: 공인중개사, 관리사무소, 이사·청소 파트너용 B2B 도구

수익을 위해 추천 순위나 안내 내용을 숨기거나 왜곡하지 않는다. 제휴 여부와 수수료 발생 가능성은 사용자가 이동하기 전에 보이게 한다.

## 7. 법률·신뢰·책임 경계

계약, 보증금, 하자, 퇴실 분쟁, 법정 기한은 고위험 영역이다.

- 일반 정보 안내와 개인별 법률·세무·중개 자문을 분리한다.
- 개인별 판단이 필요한 경우에는 자격 있는 전문가 또는 공식 기관으로 연결한다.
- 공인중개사·법률·청소·폐기물·이사 업체를 연결할 때 서비스 책임 주체, 취소·환불·분쟁 절차를 명확히 표시한다.
- 사용자 예산과 주거 정보는 최소 수집·명확한 보관·삭제 정책을 원칙으로 한다.

## 8. 확장 순서

1. 첫 자취 입주 전 준비를 사용자가 끝까지 완료하는지 검증한다.
2. 입주청소·이사·폐기물처럼 하나의 서비스 카테고리를 검증된 파트너와 연결한다.
3. 세제·침구·수납 같은 생활 맞춤 추천을 공식 상품 데이터에 기반해 확장한다.
4. 입주 후 관리와 퇴실 준비를 연결한다.
5. 계약·법률·중개 영역은 근거, 자격자 연결, 책임 범위가 마련된 뒤 별도 기능으로 연다.

## 9. 성공을 판단할 지표

- 사용자가 입주 전 준비표를 완성하는 비율
- 추천 후 `구매 후보`, `입주 후 결정`, `이미 준비함`으로 실제 결정을 남기는 비율
- 추천에서 빠진 물품과 불필요했던 물품의 비율
- 판매처·파트너 이동이 실제 구매·예약으로 이어지는 비율
- 사용자가 줄었다고 답한 준비 시간과 스트레스
- 7일·30일 재방문과 다음 주거 단계로의 재사용 비율

클릭 수만 높고 사용자가 잘못 구매하거나 불필요한 서비스를 예약한다면 성공으로 보지 않는다.
