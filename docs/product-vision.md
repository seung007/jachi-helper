# 제품 방향
현재 범위의 단일 방향 문서. 숫자·진행은 [현재 작업](current-work.md), 상품 규칙은 [비교 계약](comparison.md)에 둔다.

## 현재와 장기 목표
- 사용자 정정(2026-09-28): 생활용품·먹거리 탐색, 비교, 구매 연결이 메인이다. 대화 분석은 구매 고민·선택 조건·후보에 먼저 적용한다.
- 홈은 상품을 바로 탐색하게 한다. 준비표·조건·예산은 보조이며 강제 입구가 아니다. 예산은 입력 합계/차이만 계산하고 여유·감당 가능성을 판정하지 않는다.
- 2026-10-14 사용자 합의: 기존 품목은 유지하고 사진 표시를 개선한다. 전체 재설계 대신 메인 검색→쿠팡 상품 최대 10개→상품별 핵심 차이/상세 설명→실제 상품 구매 링크를 우선한다. 공식 응답의 순서와 웹 검색/판매량 순위는 같다고 가정하지 않는다. API 권한은 사용자 확인, 키 연결·실제 검색은 미완료다.
- 추가 지시: 서울 한정 생활 도움 사이트·생활 업소를 먼저 전량 수집하고 나중에 분류/세분화한다. 기존 서비스 4개라는 옛 상태로 새 범위 추가를 막지 않는다. 현재 승인은 [로컬 데이터 수집](seoul-life-data.md)이며 메인 교체나 새 생활 페이지 운영 배포는 아니다.
- 2026-10-15 설계 진행: 상품·우리동네·생활 서비스에 독립된 탐색 입구를 두고 관련 상황에서 연결하는 시안을 만든다. 상품이 홈의 중심인 제안이며, 대표 흐름/저장/외부 연결을 먼저 검토한다. 세부 제안과 자료 조건은 [서울 수집 문서의 화면 설계](seoul-life-data.md#화면-설계-제안-2026-10-15)에 둔다. 운영 화면 교체/배포 승인으로 확대 해석하지 않는다.
- 2026-10-16 사용자 정정: 두 동네·네 서비스 예시만으로 서울 전체 경험을 검토할 수 없다. 구→동 전체 선택, 긴 목록 대신 목적별 페이지 탐색, 설명이 있는 다양한 생활 서비스로 설계를 보완한다. 기존 상품 메인은 유지하며 상세한 제안/확인 범위는 [서울 재분석](seoul-life-data.md#서울-전체-탐색-재분석-2026-10-16)을 따른다. 현재는 재분석 단계이지 제품 구현 승인으로 확대하지 않는다.
- 2026-10-17 설계 우선 지시: 새 대화 분석 49소분류를 기존 상품과 서비스 목적에 연결하고 사용자의 문제·선택 조건에서 구매/관리/외부 실행을 이어 준다. 앱 개수 확대만으로 완성을 판정하지 않으며 [최신 연결 설계](seoul-life-data.md#대화-니즈와-앱-연결-설계-2026-10-17)의 데이터 계약·대표 흐름·전체 부족 큐를 먼저 검토한다. 이번 지시는 설계 작성이며 제품 UI 적용·커밋·배포 승인과 구분한다.
- 현재는 안내·외부 연결이다. 신청·예약·결제가 사이트 안에서 완료된다고 약속하지 않는다. 서비스 4개는 이전 시안 상태일 뿐 유지해야 할 개수나 전체 시장의 상한이 아니다.
- 장기 목표는 조건을 한 번 입력해 계약·이사·입주·생활·퇴실의 다음 행동을 이어 주는 주거 생활 실행 시스템이다. 이사·법률·일정·서비스 확장은 구매 흐름보다 후순위다.

## 차별화·확장
- 같은 용도 제품의 비용·공간·관리·호환 차이와 근거를 보여 준다. 품목·사진·링크 수를 구매 추천 완료로 대체하지 않는다.
- 채팅은 문제·누락 조건을 찾는 질적 자료다. 의견·빈도를 전체 수요·효능·인기·시세로 일반화하지 않는다. 원문을 요약으로 대체하거나 공개하지 않는다.
- 반복 구매에서 세탁 조건·보관 공간·향·소비량처럼 제품을 구분하는 조건을 재사용한다. 조건 하나만으로 적합성을 단정하지 않는다.
- 사용자 과제 관찰·누락/불필요 피드백은 개선 근거다. 초기 5명 관찰은 발견을 위한 제안이지 출시·새 지시를 막는 고정 문턱이 아니다. 변경은 최신 지시에 맞춰 기록한다.
- AI는 질문·근거 설명에 필요할 때 검토한다. 승인 범위에서 비용·사용량 제한·실패 대응을 설계하며 프레임워크를 먼저 고정하거나 규칙/산술을 LLM으로 옮기지 않는다. 가격·재고·배송·성능은 확인 데이터 밖에서 생성하지 않는다.

## 신뢰·책임
- 모델/옵션·출처를 유지하고 시험/제조사 표기/판매 관측/후기/계산/추론을 구분한다. 사진 공개 열람은 재사용 허가가 아니다.
- 광고·수수료는 이동 전에 고지하고 수익으로 순서·근거를 왜곡하지 않는다. 상품 제휴·파트너 리드·B2B는 검토 방향이지 연결 완료가 아니다.
- 계약·보증금·법정 기한·분쟁의 일반 안내와 개인별 자문을 구분해 공식 기관·자격자에게 연결한다. 서비스 책임 주체·취소·환불·분쟁 범위를 명시한다.
- 개인정보/주소는 필요한 범위만 받고 저장 위치·기간·삭제를 밝힌다. 저장 종류별 TTL을 섞지 않는다.
- 제품 찾기·비교·구매/보류 결정, 누락/잘못된 구매·재방문을 본다. 클릭만으로 구매 완료·해결·전환 증가를 선언하지 않는다.
