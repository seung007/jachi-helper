# 제품 방향
현재 범위의 단일 방향 문서. 숫자·진행은 [현재 작업](current-work.md), 상품 규칙은 [비교 계약](comparison.md)에 둔다.

## 현재와 장기 목표
- 사용자 정정(2026-09-28): 생활용품·먹거리 탐색, 비교, 구매 연결이 메인이다. 대화 분석은 구매 고민·선택 조건·후보에 먼저 적용한다.
- 홈은 상품을 바로 탐색하게 한다. 준비표·조건·예산은 보조이며 강제 입구가 아니다. 예산은 입력 합계/차이만 계산하고 여유·감당 가능성을 판정하지 않는다.
- 현재는 안내·외부 연결이다. 신청·예약·결제가 사이트 안에서 완료된다고 약속하지 않는다. 기존 서비스 4개를 유지하되 전체 시장을 대표한다고 말하지 않는다.
- 장기 목표는 조건을 한 번 입력해 계약·이사·입주·생활·퇴실의 다음 행동을 이어 주는 주거 생활 실행 시스템이다. 이사·법률·일정·서비스 확장은 구매 흐름보다 후순위다.

## 차별화·확장
- 같은 용도 제품의 비용·공간·관리·호환 차이와 근거를 보여 준다. 품목·사진·링크 수를 구매 추천 완료로 대체하지 않는다.
- 채팅은 문제·누락 조건을 찾는 질적 자료다. 의견·빈도를 전체 수요·효능·인기·시세로 일반화하지 않는다. 원문을 요약으로 대체하거나 공개하지 않는다.
- 반복 구매에서 세탁 조건·보관 공간·향·소비량처럼 제품을 구분하는 조건을 재사용한다. 조건 하나만으로 적합성을 단정하지 않는다.
- 사용자 과제 관찰·누락/불필요 피드백은 개선 근거다. 초기 5명 관찰은 발견을 위한 제안이지 출시·새 지시를 막는 고정 문턱이 아니다. 변경은 최신 지시에 맞춰 기록한다.
- AI는 질문·근거 설명에 필요할 때 검토한다. 승인 범위에서 비용·사용량 제한·실패 대응을 설계하며 프레임워크를 먼저 고정하거나 규칙/산술을 LLM으로 옮기지 않는다. 가격·재고·배송·성능은 확인 데이터 밖에서 생성하지 않는다.

## 신뢰·책임
- 모델/옵션·출처를 유지하고 시험/제조사 표기/판매 관측/후기/계산/추론을 구분한다. 사진 공개 열람은 재사용 허가가 아니다.
- 광고·수수료는 이동 전에 고지하고 수익으로 순서·근거를 왜곡하지 않는다. 상품 제휴·파트너 리드·B2B는 검토 방향이지 연결 완료가 아니다.
- 계약·보증금·법정 기한·분쟁의 일반 안내와 개인별 자문을 구분해 공식 기관·자격자에게 연결한다. 서비스 책임 주체·취소·환불·분쟁 범위를 명시한다.
- 개인정보/주소는 필요한 범위만 받고 저장 위치·기간·삭제를 밝힌다. 저장 종류별 TTL을 섞지 않는다.
- 제품 찾기·비교·구매/보류 결정, 누락/잘못된 구매·재방문을 본다. 클릭만으로 구매 완료·해결·전환 증가를 선언하지 않는다.
