# 자취도우미 기능 확장 - Council 1차 봉인

일시: 2026-08-21

## Product Lens

기존 준비표 결과를 저장 가능한 품목 단위 구매 체크리스트로 만드는 것이 체크리스트, 예산, 구매 연결을 묶는 가장 작은 사용자 흐름이다. 브라우저 저장만 사용하고, 판매처 링크 옆에는 가격 근거와 확인 기준을 분명히 해야 한다.

## Dev Lens

공유 `app.js`에 버전이 붙은 localStorage 상태를 두고, 체크리스트는 고정 ID 체크박스와 진행률·초기화로 만든다. 예산은 사용자가 직접 입력한 월 지출과 일회성 입주비를 합산해 남은 금액과 첫 달 총액만 표시한다. 계정·서버·새 의존성은 필요 없다.

## Empiricist

고정 품목 가격과 우선순위는 검증된 사실이 아니라 추정치·미검증 추천으로 남겨야 한다. 실제 사용 검증에는 30일 내 누락 구매, 동일일 판매처 가격과의 차이, 링크 도착·가격 일치 여부가 필요하다.

## Steward

체크·예산 입력은 생활과 지출 맥락을 드러낸다. 저장 위치를 명확히 하고, 예산 결과가 감당 가능성 판정으로 보이지 않게 해야 한다. 외부 판매처·제휴·추적 링크가 없으면 그 사실도 밝혀야 한다.

## Adversary

재방문·기기 간 사용 수요가 아직 증명되지 않았고, 상세 예산·판매처 링크는 실제 가격과 재고를 검증하지 못하면 오도로 보일 수 있다. 따라서 동기화·실시간 가격·상품 추천·제휴는 금지하고, 사용자의 직접 입력과 일반 검색 링크를 넘지 않아야 한다.
