# 준비물 39개 → 57개

> 필요시 읽는 당시 근거/검토 기록이다. 최신 상태는 [현재 작업](current-work.md), 방향·실행 규칙은 [제품 방향](product-vision.md)과 [AGENTS](../AGENTS.md)를 따른다. 아래 제안·실험 문턱·당시 승인·집계는 현재 명령이나 새 작업의 승인으로 재사용하지 않는다.

사용자 요청에 따라 18개 품목을 추가했다. 전체를 필수품으로 취급하지 않고 품목별 구매 전 확인·나중에 결정 기준을 유지한다. 기존 품목 ID와 저장 상태는 바꾸지 않는다.

| 분류 | 추가 품목 |
|---|---|
| 침구·수면 | 베개 커버, 수면 안대 |
| 욕실 | 욕실화, 배수구 거름망, 변기솔, 헤어드라이어 |
| 주방 | 식도·주방칼, 도마, 수세미, 식기 건조대, 채소 필러, 국자 |
| 청소 | 청소용 걸레, 압축 뚫어뻥 |
| 세탁 | 돌돌이·테이프 클리너 |
| 생활·수납 | 줄자, 드라이버, 실내 슬리퍼 |

선정 기준은 기존 목록에서 빠진 손질·설거지·욕실 관리·공간 실측 용도다. 단톡방의 통계적 수요나 인기순으로 선정했다는 주장은 하지 않는다. [IKEA 제품 분류](https://www.ikea.com/kr/ko/cat/products-products/)는 도마·주방칼 등 생활용품 분류를 확인하는 참고로만 사용했으며 필수품 판정 근거는 아니다.

## 구현

- 기존 공통 카탈로그에 추가하여 홈 검색·카테고리·정렬·상세·보유품 선택·결과에 함께 반영한다.
- 모든 신규 품목에 개별 안내, 확인 기준, 검색어와 이미지 위치를 지정했다.
- 홈/메뉴의 개수와 공유 문구는 카탈로그에서 자동 계산한다. HTML 초기 표시도 57개로 맞췄다.
- 기존 제목·SEO 실험과 가격·인기순 정책은 변경하지 않았다. 공개되지 않은 제품 가격·성능을 생성하지 않았다.
- 앱 스크립트 버전을 변경해 이전 39개 목록이 캐시에 남지 않게 했다.

## 이미지 기록

- 도구: 내장 ImageGen, 브랜드 없는 품목 구분용 생성 이미지. 실제 판매 상품 사진이 아니다.
- 경로: `assets/home-item-expanded.webp`, 720×1440, 약 257KiB. Sharp로 크기와 WebP 형식만 최적화했다.
- 3열×6행, 왼쪽에서 오른쪽으로 순서: 베개 커버 / 안대 / 욕실화; 거름망 / 변기솔 / 드라이어; 식도 / 도마 / 수세미; 식기 건조대 / 필러 / 국자; 걸레 / 뚫어뻥 / 돌돌이; 줄자 / 드라이버 / 실내 슬리퍼.
- 생성 프롬프트: 단일 1:2 세로 캔버스에 동일 크기 정사각형 18칸, 3열×6행, 칸마다 위 순서의 생활용품 하나를 중앙에 배치. 옅은 차가운 회색 배경, 선명한 스튜디오 실사풍, 글자·로고·테두리·장식 없음, 품목은 칸 경계 안에 완전히 들어오게 구성.
- 전체 원본과 브라우저에서 잘린 품목 이미지를 확인한다. 기존의 무관한 카테고리 사진을 재사용하지 않는다.

## 검증

- `npm run check`: 57개 ID/이름/안내/이미지 경로/구매 링크 검사.
- `npm run verify:decision`: 57개 펼치기, 신규 이미지 18개 서로 다른 위치, 도마·거름망·줄자 검색과 상세, 도마 보유 상태 저장·새로고침 검사 포함.
- 커밋·배포는 사용자 승인 전 하지 않는다.

검증 결과: 위 두 명령 모두 통과했다. 신규 품목 대표 카드의 390/768/1440px 가로 넘침이 없으며 도마·거름망·줄자 이미지와 명칭을 직접 대조했다. 보유 도마를 결과에서 제외하고 새로고침 뒤에도 보유 상태가 유지되는 것을 확인했다.
